## 第三天学习笔记：JavaScript 进度控制与本地存储

今天继续完成第 0 章第一节后的学习仪表盘练手项目。本次练习仍然不是正式学习完整的 JavaScript 章节，而是通过少量代码熟悉“输入、运行、观察、调试、复盘”的学习过程。

## 一、今天完成的内容

### 1. 同步进度条和百分比文字

- 使用 `querySelector("#progressPercent")` 获取百分比元素
- 在 `setProgress(value)` 中同时修改进度条宽度和百分比文字
- 让同一个 `value` 控制多个页面元素

### 2. 使用条件判断限制进度

- 使用 `if` 判断进度是否大于 `100`
- 使用 `else if` 判断进度是否小于 `0`
- 将进度限制在 `0～100` 之间
- 使用 `if / else` 根据用户点击“确定”或“取消”执行不同操作

### 3. 使用变量保存当前状态

- 使用 `let currentProgress` 保存当前进度
- 理解 `let` 保存的数据可以变化
- 在 `setProgress()` 中用 `currentProgress = value` 同步变量

### 4. 使用浏览器本地存储

- `localStorage.setItem()`：保存进度
- `localStorage.getItem()`：读取进度
- `localStorage.removeItem()`：删除进度
- 使用 `Number()` 把读取到的文本转换为数字
- 没有保存记录时，将 `75` 作为默认进度
- 刷新页面后仍然保留当前进度

注意：`localStorage` 是浏览器本地存储，控制台只是调试和观察程序的工具，两者不是同一个东西。

### 5. 使用控制台调试

- 使用 `console.log()` 查看变量的实际值
- 在控制台输入 `currentProgress` 检查当前进度
- 认识到控制台显示 `undefined` 不一定是错误
- 发现 `progress` 和 `Progress` 不相同，JavaScript 区分大小写

### 6. 完成一个点击练习

- 点击百分比数字时执行事件函数
- 每次使用 `currentProgress + 5` 增加进度
- 达到 `100` 后通过条件判断阻止进度继续增加
- 新进度自动保存到本地存储

## 三、今天理解的执行流程

点击百分比数字后：

1. 读取 `currentProgress`
2. 计算 `currentProgress + 5`
3. 把结果作为 `value` 传给 `setProgress()`
4. 检查进度是否超出 `0～100`
5. 更新 `currentProgress`
6. 更新进度条和页面文字
7. 将新进度保存到 `localStorage`
