### 2. JavaScript 基础练习

今天主要编辑了 `project/2026-11-20/learning-dashboard/script.js`。

练习了：

- 使用 `document.querySelector()` 查找 HTML 元素
- 使用 `textContent` 修改标题和介绍文字
- 使用 `#id` 和 `.class` 查找不同元素
- 使用 `addEventListener()` 监听按钮点击
- 使用 `function` 定义函数
- 使用函数参数 `value`
- 使用 `element.style.width` 修改进度条宽度
- 点击按钮后调用 `setProgress(0)`，将进度条归零

目前进度条是手动设置的：

```js
setProgress(75);
```

这表示现在只是练习 JavaScript 修改页面样式，还没有实现真正的任务统计、复选框联动或进度保存。

## 二、今天理解的 CSS 概念
        
- `body`、`.class`、`#id` 的选择方式
- `margin` 和 `padding` 的区别
- `width`、`max-width` 的作用
- `background-color`、`color`、`border-radius`
- `display: flex` 的基础用途
- 后代选择器，例如 `.hero h1`

## 三、今天理解的 JavaScript 概念

- JavaScript 可以找到 HTML 元素
- JavaScript 可以修改网页文字
- JavaScript 可以修改 CSS 样式
- JavaScript 可以监听用户点击
- 函数可以接收参数并重复使用
